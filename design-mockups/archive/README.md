# Design archive

Static reference mockups kept for future design iterations — **not** part of the live app.

- **`form-v2.html`** — the standalone HTML mockup that the live public form's **v2 redesign** was based on (numbered questions, option chips instead of dropdowns, dark theme + neon-green accent). The production version of this design lives in `app/page.tsx` + the "Public form — v2 redesign" section of `app/globals.css`, dialed back to the app's mint-green and wired to real config + Turnstile. Open this file in a browser when you want a clean reference for further form tweaks.
